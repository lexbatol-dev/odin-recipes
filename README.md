# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

This project is a basic multi-page website featuring a home page with links to three recipe pages: Lasagna, Spaghetti Carbonara, and Jollof Rice. Each recipe page includes an image, description, ingredients list, and step-by-step cooking instructions.

## Skills demonstrated

- Writing semantic HTML (headings, lists, figure/figcaption)
- Structuring a multi-page site with relative links
- Organizing project files and folders
- Using Git and GitHub for version control
